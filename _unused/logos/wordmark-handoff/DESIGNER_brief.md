# Designer Brief — Vivid Sub-Brand Wordmarks

## What you're designing

Three sub-brand wordmarks for an aftermarket performance parts company, in the existing brand's hand-drawn italic chunky tuner letterform style.

## Deliverables

Six SVG files at 1:1 vector quality, no rasterization:

| File | Word | Treatment |
|------|------|-----------|
| `vr-trucks-red.svg` | vrtrucks | Red body, creme outline (light bg) |
| `vr-trucks-creme.svg` | vrtrucks | Creme body, red outline (dark bg) |
| `vr-muscle-red.svg` | vrmuscle | Red body, creme outline |
| `vr-muscle-creme.svg` | vrmuscle | Creme body, red outline |
| `vr-powersports-red.svg` | vrpowersports | Red body, creme outline |
| `vr-powersports-creme.svg` | vrpowersports | Creme body, red outline |

## Reference assets in this folder

- `REF_vividracing_master.png` — the master wordmark to match in style
- `REF_vividracing_red.svg` — vector source (Illustrator-compatible)
- `REF_vividracing_red.png` — rendered version for visual reference
- `REF_VR_monogram_red.svg` — the VR monogram (used in headers, for sizing reference)
- `REF_VR_monogram_red.png` — rendered version

The new wordmarks are NOT lockups with the VR monogram. They are standalone wordmarks like vividracing is. The VR monogram lives separately on each page header.

## Construction specs

- **Italic lean:** ~12° forward
- **Stroke weight:** heavy — roughly 25% of cap height
- **Corner radius:** ~50 units in a 1000-unit cap-height system — rounded chunky terminals
- **Outline thickness:** ~10–14% of cap height (thick, sticker/decal grade)
- **Tracking:** tight, letters touch or near-touch
- **Inner highlight:** preserve the creme inner reflection line inside each red letter
- **Outer wrap:** single continuous creme outline around the whole wordmark, not per-letter

## Colors

- Heritage Red: `#B31414`
- Avorio Creme: `#F4F1EA`

## Letterform sources you can borrow from

From `vividracing`, the letters available are: v, i, d, r, a, c, n, g
Letters you'll need to draw new in matching style: t, u, k, s, m, l, e, p, o, w

- `u` can be derived from `n` (similar two-stem + curve structure, inverted)
- `t` shares ascender DNA with `d`
- `m` extends `n`'s arch logic
- `o` and `e` share curved DNA with `c`
- `p` shares stem DNA with `r`
- `l` shares ascender DNA with `d` (no flag)
- `k`, `s`, `w` are mostly new construction

## Sibling test

Put your finished wordmarks next to vividracing and squint. They should read as a family. If one looks like it came from a different era or hand, redo.

## Format

Final delivery as SVG files, single coherent paths per wordmark, no rasterized elements. Test that they scale from 16px to 800px without losing legibility.
