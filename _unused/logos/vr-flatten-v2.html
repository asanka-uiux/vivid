Vivid · VR Mark · JND Flatten v2 · Vector Reconstruction

The VR Mark. Same Silhouette. Properly Flattened.

v2 fixes both pieces of feedback. Source moved from VR_FullColor_logo.png to VRLogo_Outline.eps — the actual vector source from Drive. Result: clean Bézier paths instead of raster artifacts. And the sub-brand pages now use the VR mark by itself, not a VR mark with typeset letters glued next to it.

What changed since v1

  • Vector, not raster. v1 was traced from the PNG using morphological operations on pixels — left rough edges. v2 is the actual Illustrator outline from VRLogo_Outline.eps, converted EPS → PDF → silhouette mask → vectorized to a single clean Bézier path.
  • No patched letters. v1 glued "TRUCKS"/"MUSCLE"/"POWERSPORTS" in Inter Black next to the VR mark — different letterform DNA, didn't read as one mark. v2 uses the VR mark by itself. Sub-brand identification lives in the family switcher tab and the page nav, not in the wordmark.
  • Two-layer construction matches the master. Same approach as vividracing — solid Heritage Red silhouette with Avorio Creme inner highlight detail preserved from the original chrome construction.

Why the VR mark stands alone on each sub-brand

Same Gap Inc / Marriott pattern: the parent uses the full wordmark, each child uses a shared monogram. Sub-brand identification is communicated by the active state in the family switcher (top), the page's category nav, and the saved-vehicle context — not by gluing typeset letters onto the wordmark. The previous lockups (VR + "TRUCKS" in Inter Black) created two-letterform-DNA conflicts; this version doesn't.
