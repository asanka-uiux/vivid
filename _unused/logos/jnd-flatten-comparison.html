What still needs a designer

  1. Sub-brand variants. The letterforms in this wordmark are custom — not from any font you can buy. To produce vividtrucks, vividclassics, and vividx as authentic sub-brands, a designer needs to open the source .ai file and redraw the new suffix letters using the existing letterform DNA. This is a 1-2 hour job per variant. The source files are saved at /logos/flat-system/vivid-source-outlines.svg and the original vivid logo full color.ai on Drive.
  2. The inner outline detail. The current flatten preserves the inner outline that appeared as the chrome highlight. A designer should decide: keep it (more recognizable, two-color treatment) or remove it for a purely single-ink master. Both options are valid — depends on the application surface.
  3. Logo system documentation. Once the four sub-brand variants exist, the playbook's Brand Architecture section should include a Logo System slide with master + four sub-brands + usage rules (light/dark, minimum size, clear space, what not to do). I'll build that slide once the variants are in vector.
